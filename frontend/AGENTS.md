# Общие правила фронтенда

- Меняйте только `frontend/`. Не изменяйте FastAPI, `run_agent()`, инструменты
  агента, серверную логику и исходные данные за пределами этой папки.
- Используйте только переданный CSV или подготовленный JSON. Не добавляйте
  анкеты и не придумывайте фотографии, рейтинги, отзывы или контакты.
  Сохраняйте `synthetic`, `price_imputed`, `city_imputed` для каждого исходного id.
  `src/mocks/profiles.json` — точная копия переданного `../profiles.json`;
  копирование источника не должно изменять или дополнять анкеты.
- Доступ к данным проходит через `src/services/vendorService.ts`. Пока работает
  локальная mock-реализация без запросов к бэкенду; компоненты не импортируют
  набор данных или mock-реализацию напрямую.
- Показывайте подпись «Демонстрационный режим». Заглушки не должны сообщать
  об успешной отправке заявки или бронировании.
- Оформление: фон `#F4FBF9`, плотные белые панели, светлые зелёные и голубые
  оттенки, мягкие градиенты и `backdrop-filter: blur(12px)` для панелей.
  Сохраняйте читаемость текста и однотонный запасной вариант без blur.
- После каждой задачи выполняйте проверку (как минимум `npm run build` из
  `frontend/`) и создавайте отдельный коммит. Следующую задачу начинайте только
  после отдельного задания пользователя.
