# HackAlem: подбор event подрядчиков

Сервис принимает параметры мероприятия и возвращает до трёх подходящих карточек из 66 профилей. Сначала применяются жёсткие условия, затем оставшиеся кандидаты упорядочиваются по упоминанию формата мероприятия в описании, цене «от» и ID. Результат повторяем: внешний AI API и случайность не используются.

## Запуск

Нужен Python 3.10+. В Windows PowerShell откройте папку проекта и выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app:app --reload
```

На macOS/Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn app:app --reload
```

Откройте http://127.0.0.1:8000/docs, выберите `POST /match`, нажмите **Try it out** и вставьте запрос:

```json
{
  "city": "Алматы",
  "event_date": "2026-10-17",
  "event_format": "свадьба",
  "category": "Ведущий",
  "budget_kzt": 1000000,
  "duration_hours": 5,
  "language": "русский"
}
```

Также доступен `GET /health`: он показывает, сколько профилей прочитано из `profiles.json`. Путь к данным определяется относительно `app.py`, поэтому сервер не зависит от текущей рабочей папки.

## Контракт API

`POST /match` принимает город, дату, формат, категорию и бюджет в тенге. Поля `language` и `duration_hours` необязательны. По умолчанию дата должна быть между **2026-09-23** и **2026-12-31** включительно; некорректные запросы получают HTTP 422. Границы можно настроить переменными окружения `MATCH_FIRST_DATE` и `MATCH_LAST_DATE` в формате `YYYY-MM-DD`. Названия города, формата, категории и языка сравниваются без учёта регистра и лишних пробелов. Пользователь передаёт названия категорий и форматов из датасета (например, `Банкетный зал`, `конференция`).

Ответ содержит `status`, `message`, `total_matches`, `exclusions` и `recommendations` (0–3 карточки). Статусы:

| Статус | Значение |
| --- | --- |
| `matched` | Есть хотя бы один подходящий профиль |
| `no_category_in_city` | В данном городе нет профилей нужной категории |
| `no_matches` | Профили есть, но все отсечены условиями |

В `exclusions` показано, сколько профилей отсеялось на каждом шаге. Каждый профиль учитывается только один раз: проверка даты → формата → цены «от» → языка → часов. `total_matches` считает всех подходящих до ограничения тремя карточками. В `message` поясняются пустой результат, дефицит кандидатов и занятость на выбранную дату.

Каждая карточка содержит анонимное имя, категорию, город, цену «от», объяснение с конкретным фрагментом описания и флаги `synthetic`, `city_imputed`, `price_imputed`. Цена «от» не выдаётся за окончательную стоимость. Значение `max_hours: null` в данных означает услугу без почасового присутствия (флористика, декор, сувениры): ограничение по часам к ней не применяется.

## Три сценария для демонстрации

В `/docs` меняйте тело `POST /match`:

1. **Плотная категория:** приведённый выше запрос для `Ведущий`. Измените дату на `2026-12-26` и сравните карточки и `exclusions.busy_date`.
2. **Редкая категория:** `city: Алматы`, `event_date: 2026-09-23`, `event_format: свадьба`, `category: Флорист`, `budget_kzt: 500000`. Здесь `duration_hours: 8` не отсекает профили с `max_hours: null`.
3. **Нулевой результат:** те же параметры, что у флориста, но `budget_kzt: 0`. Получите `no_matches` и текст причины. Для `no_category_in_city` запросите `category: Флорист`, `city: Зарубежье`.

## Данные и файлы

| Файл | Назначение |
| --- | --- |
| `data/hackathon_dataset_anonymized.csv` | Исходные 66 профилей |
| `prepare_profiles.py` | Разбирает списки, цену и календарь из CSV |
| `profiles.json` | Подготовленные данные, которые читает API |
| `matching.py` | Валидация запроса, отбор, ранжирование, объяснения |
| `app.py` | HTTP маршруты FastAPI |
| `tests/test_matching.py` | Границы календаря, доступность, условия, порядок и статусы |

Чтобы воспроизвести подготовку данных:

```bash
python prepare_profiles.py data/hackathon_dataset_anonymized.csv profiles.json
```

Чтобы запустить проверки, установите тестовые зависимости и выполните (на Windows вместо `python` используйте `.\.venv\Scripts\python.exe`, на macOS/Linux — `.venv/bin/python`):

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
```
